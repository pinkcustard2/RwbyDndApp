<h1>RWBY D&D App</h1>

RWBY D&D app is an app similar to D&D Beyond developed in Kotlin and Jetpack Compose for a custom Dungeons and Dragons campaign inspired by the TV show RWBY

Currently contains only character creation - levelling of character, backstory, notes and rules are currently not yet implemented
